This repository is our public showcase: working demos, sample projects, and tutorials that show how we build. Everything here is self-contained, runs on free tiers, and uses fictional data only.

## What we do

- **AI App Rescue** — we repair and finish apps built with AI tools: broken logins, payments, data handling, and App Store rejections, taken through to production-ready.
- **AI Chatbots** — customer-support chatbots grounded in your own FAQs and documents, with a clean handoff to a human when the bot doesn't know.
- **API Integration** — Stripe payments and webhooks, third-party API integrations, and workflow automation (billing, receipts, notifications).

How we work: **AI tools for speed, human review and automated testing for reliability.**
